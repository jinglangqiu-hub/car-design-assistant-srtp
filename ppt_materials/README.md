# Historical defense materials

This directory preserves the original SRTP defense archive, not maintained application source or publication instructions. Use the [current overview](../README.md), [experiment record](../docs/experiments.md), and [run guide](../docs/reproduction.md) for current claims.

- `01_report_and_docs/`: report, presentation, outlines.
- `02_generated_samples/`: original sports outputs and metadata.
- `03_training_records/manifest.txt`: original training and continuation records.
- `04_dataset_and_model_info/`: historical counts/mapping. Statements about dataset uploads are superseded by the [data notice](../THIRD_PARTY_NOTICES.md).
- `05_desktop_and_packaging/`: source/configuration snapshots; maintained files are in `app/` and `scripts/`.
- `06_github_release/`: historical summary; script entry points delegate to maintained scripts to avoid obsolete dataset uploads.

No missing metric, sample, GUI screenshot, or training result has been reconstructed as if it were original evidence.
